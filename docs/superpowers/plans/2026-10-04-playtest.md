# Mode test solo — Plan d'implémentation

> **Pour l'implémenteur :** exécuter les tâches dans l'ordre, en TDD pour le moteur (test qui échoue → code minimal → test qui passe → commit). L'interface est vérifiée dans un vrai navigateur aux points d'étape. Cases à cocher `- [ ]`.

**Objectif :** un mode test solo pour les decks importés : plateau avec glisser-déposer, pioche, mulligan, tours, marqueurs, jetons, bibliothèque, taxe de commandant, annuler, journal et sauvegarde dans le navigateur.

**Architecture :** moteur pur dans `lib/game/` (`applyAction` déterministe, hasard à graine, partie = liste d'actions rejouable avec snapshots), interface React dans `components/playtest/` avec `@dnd-kit/core`, page `/decks/[id]/test` alimentée par le catalogue construit depuis `listDeckCards`.

**Stack :** Next.js 15 (edge), React 18, TypeScript strict, Tailwind, Lucide, `@dnd-kit/core`, Vitest ; vérification visuelle avec Chromium (`/opt/pw-browsers`) piloté par `playwright-core`.

**Spec :** `docs/superpowers/specs/2026-10-04-playtest-design.md`

## Contraintes globales

- `STARTING_LIFE = 40`, `OPENING_HAND = 7`, `SNAPSHOT_EVERY = 20`, `COMMANDER_TAX_STEP = 2`.
- Premier mulligan gratuit : `bottomCount(state) = max(0, stats.mulligans − 1)`.
- Journal en français ; nom de carte = `printed_name` de la version FR si présent, sinon nom anglais, **quelle que soit la langue d'affichage**. Carte cachée (vers ou depuis la bibliothèque, ou face cachée) = « une carte ».
- `zones.library[0]` = dessus de la bibliothèque.
- Positions sur le champ de bataille en % (0–100), bornées.
- Identifiants : `c${ref}-${n}` (n à partir de 1) pour un exemplaire, `t${n}` pour un jeton.
- Hasard : mulberry32 + Fisher-Yates ; graine d'une nouvelle partie via `crypto.getRandomValues`.
- Sauvegarde : clé `dc-playtest-<deckId>`, valeur `{ version: 1, fingerprint, actions }`, tous les accès dans un `try/catch`.
- Langue d'affichage : clé `dc-card-lang` (déjà utilisée par `/decks/[id]`).
- Glisser-déposer : `PointerSensor` (seuil 5 px) et `TouchSensor` (appui 200 ms).
- Raccourcis : `D`, `U`, `N`, `S`, `M`, `Ctrl/Cmd+Z`, `Échap`, ignorés pendant la saisie dans un `input` ou un `textarea`.

## Points de vigilance (Review Focus)

1. **Déplacer une carte dans sa propre zone** (réordonner la bibliothèque, repositionner sur le champ de bataille) ne doit ni la dupliquer ni la perdre. → test Tâche 3.
2. **Annuler juste après un mulligan** doit redonner exactement la main précédente (déterminisme du hasard). → test Tâche 5.
3. **Jeton envoyé en main puis annulation** : le jeton disparaît, puis réapparaît identique après l'annulation. → test Tâche 5.
4. **Sauvegarde d'un deck réimporté depuis** : ignorée, sans plantage. → test Tâche 5 (empreinte différente).
5. **Raccourci tapé dans le champ de recherche de jetons** (par exemple « d ») : aucune pioche. → garde testée dans `isTypingTarget` (Tâche 11).

  - `start { seed: 1 }` : 7 en main, bibliothèque de 25, `stats.drawn === 7`, journal `['Début de partie']` ; même graine → même main.
