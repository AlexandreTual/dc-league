# Adaptation tablette de la table — plan

> **Pour les agents :** chantier traité dans une seule PR (issue #81), un commit par tâche, dans l'ordre. Cases à cocher (`- [ ]`) pour le suivi.

**But :** jouer à la table sur une tablette en paysage : zones tactiles de 44 px, colonne resserrée, aperçu de carte dans le menu ouvert par l'appui long, message en portrait.

**Architecture :** tout passe par une variante Tailwind `tablet:` (`@media (pointer: coarse)`) posée sur les composants existants de `components/table/`. Le seul changement de comportement en JavaScript est l'image dans le menu : `MenuPoint` porte `touch: true` quand le menu vient d'un appui long, et la table passe alors l'image (`menuPreview`, fonction pure testée) à `CardMenu`. Moteur et état de partie inchangés.

**Spec :** `docs/superpowers/specs/2026-10-06-tablet-design.md`.

## Contraintes communes

- Repères des scripts inchangés : `data-board`, `data-column`, `data-panel`, `data-bubble`, `data-zone` + `data-player` + `data-count`, `data-card-id`, `player-name`, `player-life`, `hand-count`, `preview`.
- Noms accessibles inchangés pour les boutons de vie et « Compteurs de … ».
- Rien ne change à la souris : `playtest-check` et `online-check` passent sans modification.
- Vérifications : `npm test`, `npx tsc --noEmit`, `npm run lint`, `npx @cloudflare/next-on-pages`, `playtest-check`, `online-check`, `playtest-tablet-check`.
